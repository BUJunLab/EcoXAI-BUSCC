## Bugs

Fixed today:

- `reset.sh` deleted all results — now archives first (`9c6a18f`).
- Driver never tracked jobs → double explore, never-ending driver (`2e6a8ae`).
- `smoke.qsub` archived empty workspaces instead of `assets/` (in `scc/pipeline.qsub`).

Found, not fixed:

- Orchestrator keeps the hypothesis queue in memory only. Deleting hypotheses via the API does not remove them from the queue; the only way to rebuild it is a backend restart. Should read from DB per pop.
- `_retryStage` ignores `autoMode`, and a stopped job (exit 137) counts as a failure, so stopping a job while paused still spawns up to 3 retries. Stop needs to bypass retry.
- Analyze on a deleted hypothesis: the skill's text match fails and it falls back to *all* hypotheses — an expensive silent misfire.
- `maxHypothesisCycles=1` means one *regeneration*, i.e. two hypothesize rounds. The naming misleads; 0 = single round.
- The driver does not survive a backend restart (no WS reconnect).

## Design conclusions

EcoXAI is a fixed procedure (explore → hypothesize → per-hypothesis analyze →
verdict → repeat) with free content inside each step. It automates the
hypothesis–test labour, not the scientific judgement: agents grade their own
work, there is no reviewer, no rollback, no replication, and "learn" means only
"do not regenerate what exists".

For drug repurposing, the plan (details in chat, to be written up as
`docs/design-repurposing.md`):

- Modules: `assemble → explore → retrieve(KG) → hypothesize → analyze → review → synthesize`.
- KGs: AlzKB (candidates, mechanism chains), Open Targets (L2G mapping, tractability), PrimeKG/DRKG (indication labels, negatives), ChEMBL/DrugCentral (action type → direction), ClinicalTrials.gov (trial-entry label), LINCS + AMP-AD DEG (signature reversal).
- Modifications: drug×target long table with direction; entity-level hypothesis types with mandatory mechanism chain; analyze skeleton = ablation + negative controls + precision@k; reviewer stage; hypothesis queue in DB; verdict schema gains `ablation_robust`, `negative_control_p`, `contradicts`.
